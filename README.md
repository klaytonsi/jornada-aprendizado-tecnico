# Jornada de Aprendizado Técnico

🇧🇷 **Português**

Este repositório registra minha evolução durante a construção de uma base técnica em Python, SQL, raciocínio lógico, pensamento crítico, análise de dados e fundamentos de Inteligência Artificial.

O objetivo não é apenas armazenar exercícios, mas documentar como estou aprendendo: o que estudei, como raciocinei, quais erros encontrei, como corrigi meus problemas e quais assuntos ainda preciso desenvolver.

## Objetivos

- Construir uma base sólida em Python.
- Aprender SQL progressivamente.
- Desenvolver raciocínio lógico e pensamento crítico.
- Estudar fundamentos de análise de dados.
- Conhecer fundamentos de Inteligência Artificial.
- Praticar por meio de exercícios e projetos.
- Registrar dificuldades e aprendizados reais.
- Construir evidências concretas da minha evolução técnica.

## Fontes de estudo

### freeCodeCamp

Estudos de Python e SQL, incluindo exercícios e conteúdos relacionados aos fundamentos.

### Data Science Academy

Estudos introdutórios relacionados a análise de dados e Inteligência Artificial.

## Organização

```text
python/                # Estudos e exercícios de Python
sql/                   # Estudos e exercícios de SQL
raciocinio-logico/     # Problemas e exercícios de lógica
pensamento-critico/    # Estudos e exercícios de pensamento crítico
analise-de-dados/      # Fundamentos e práticas de análise de dados
inteligencia-artificial/ # Fundamentos de IA
data-science/          # Fundamentos de ciência de dados
progresso/             # Registro da evolução e dificuldades
```

## Como documento meus estudos

Cada assunto relevante pode registrar:

- O que aprendi
- Como funciona
- Exemplos
- Meu raciocínio
- Erros e dificuldades
- O que aprendi com os erros
- Prática
- Próximos passos

A documentação representa meu aprendizado real e não pretende apresentar conhecimentos ou experiências que ainda não desenvolvi.
